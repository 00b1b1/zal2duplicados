# Recursos de marca

`dhl-logo.svg` y `dhl-icon.svg` se extrajeron sin redibujar de los SVG usados en la cabecera pública del DHL Brand Hub (https://www.brandhub.dhl/en, 26-09-2026). `src/assets/dhl-logo.png` es una conversión local del SVG para jsPDF.

El icono de color se usa en el favicon de acuerdo con la guía de DHL Icon. Los colores aplicados son Postyellow `#FFCC00` y DHL Red `#D40511`. No se incluye la tipografía Delivery porque su descarga se rige por términos específicos; se usa Arial como alternativa segura.
